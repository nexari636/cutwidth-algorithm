# Algoritmo Cutwidth

## Autor
**Nombre:** Jhon Byron Leturne Pluas

## Descripción

Este proyecto implementa el **Algoritmo Cutwidth**, cuyo propósito es calcular y optimizar el ancho de corte en grafos. El ancho de corte es una medida importante en la teoría de grafos que ayuda a evaluar la capacidad de separación entre diferentes conjuntos de nodos.

## Requisitos

Para ejecutar este proyecto, asegúrate de tener instalada la siguiente tecnología:
- Java (JDK 19)
- NetBeans

Tambien cuenta con version web la cual se encuentra divida en Servidor y Vista utiliza las siguientes tecnologias:
- Java (JDK 11)
- AngularJS
- Jquery
- SpringBoot (Servidor)
- GoJS
